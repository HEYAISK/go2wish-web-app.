# GO2WISH Mobile Web App — Version 1

A responsive, static mobile web app starter built with HTML, CSS, and JavaScript.

## Files
- `index.html` — home screen, catalog, services, portfolio and contact sections
- `styles.css` — responsive dark navy / electric blue / gold design
- `app.js` — WhatsApp enquiry buttons, navigation and local portfolio preview
- `manifest.webmanifest` — installable-app metadata
- `sw.js` — basic offline cache for HTTPS hosting
- `assets/go2wish-logo.png` — supplied GO2WISH logo

## WhatsApp number
Your WhatsApp number is already configured in `app.js` as `9040669652`. If you ever need to change it, use the international format with digits only (country code + 91), without plus signs, spaces, or dashes.

## Test on your phone
You can open `index.html` locally for a quick layout preview. WhatsApp buttons and install/offline features work best when the app is hosted over HTTPS.

## Free hosting with GitHub Pages
1. Sign in to GitHub and create a new public repository named `go2wish-web-app`.
2. Upload the files and the `assets` folder from this package to the repository root.
3. Open the repository's **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the published URL to appear in the Pages section.
6. Open the URL on your phone. Use your browser menu's **Add to Home screen** or **Install app** option if offered.

Free hosting terms and available features can change. GitHub Pages is for static sites; it does not provide a database, order-management backend, or secure payment processing.

## Add real portfolio work
The upload area in Version 1 previews selected images/videos in your browser only; it does not publish them. To show portfolio work to all visitors, add optimised image/video files to the repository and create portfolio entries in `index.html`.

## Before launch
- Replace the WhatsApp placeholder.
- Check all brand text and contact details.
- Add only photos/videos you have permission to publish.
- Test links on mobile and desktop.
